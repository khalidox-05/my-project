# Landing Page Project

Une application web simple et responsive (Landing Page) développée dans le cadre d'un projet collaboratif avec gestion de backlog et des tâches sur GitHub.

## Aperçu du Projet
Ce projet présente une page d'accueil moderne (Landing Page) comprenant :
- Un en-tête (Navbar) réactif.
- Une section héroïque (Hero Section) avec appel à l'action.
- Une section de présentation des fonctionnalités (Features).
- Un formulaire de contact et un pied de page (Footer).
